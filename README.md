# Kas Bulanan
1. Jalankan schema.sql di Supabase SQL Editor.
2. app.js sudah memakai Project URL dan Publishable key Supabase yang digunakan sebelumnya.
3. Tes lokal dari C:\xampp\htdocs\kas-bulanan dengan http://localhost/kas-bulanan/ atau upload ke Netlify.
4. Netlify tidak menjalankan schema.sql; SQL cukup dijalankan sekali di Supabase.
5. Jangan pernah memasukkan secret/service_role key ke frontend.
